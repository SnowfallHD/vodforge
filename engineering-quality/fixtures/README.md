# Generated fixtures

The harness generates deterministic audiovisual fixtures from FFmpeg's `testsrc2` and `sine` filters at run time. No fixture contains third-party creative work. Binary fixtures live in the ignored run workspace so the repository does not accumulate media blobs.

The local HTTP fault server exposes normal, throttled, interrupted, retryable, malformed, Unicode-title, metadata-rich, and thumbnail routes over loopback only.
